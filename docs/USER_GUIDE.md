# A股科技决策看板使用说明

## 日常流程

1. 收盘后在“我的交易模型”录入当天大盘六项判断。
2. 在“持仓管理”录入六个槽位的股票和实际金额，检查总仓位与单股止损风险。
3. 点击“Save portfolio snapshot”保存当天快照。
4. 新交易先在“交易计划与复盘”记录逻辑、失效条件、计划仓位和止损止盈。
5. 退出后补充复盘备注，并按需导出 CSV。

## 数据管理

- “数据导入”支持 CSV、XLSX、XLS。
- 股票池模板可直接下载后填写。
- 导入文件保存于 `data/imports/`，不会覆盖旧文件。
- 交易计划与持仓快照保存于项目根目录的 `decision.db`。

## 启动

Windows 本地启动：运行 `run_local.ps1`，然后访问 `http://127.0.0.1:8505`。

本工具用于研究、纪律和复盘，不自动下单，也不构成投资建议。
