# 热点资讯更新

每天北京时间08:30、12:00、16:00更新，包括周末。三个独立线程定时任务避免不同分钟组合引起额外触发。需要本机开机联网、Codex可执行；此配置不是云端常驻服务，不承诺关机时运行。

手动采集：`python -m src.news_refresh --directory data/news`。页面刷新后读取本地结果，不在渲染期间联网。来源状态、最近成功时间、超过12小时过期提示与本次新增/修订数分开显示。

已实采：中国人民银行公开新闻列表、中国新闻网财经列表、巨潮沪深京最新公告抽样、国家统计局年度计划日程。只保留标题和原文链接，不复制文章全文。列表未取得独立发布时间时标注未知，采集时间不冒充发布时间。媒体报道不自动等于事实确认，也不生成买卖建议。

2026-10-14补齐：巨潮列表公开页面脚本使用POST查询，GET错误不代表查询不可用。按该公开接口分别查询沪、深、北最新列表，每市场一页、最多50条文档，不声称公告全集。源announcementTime保留为披露时间，PDF来自官方静态文档域名。

国家统计局年度表格按rowspan/colspan展开，验证年份、月份、日、星期及时间。计划发布时间保存为scheduled_at，网页发布时间仍可为未知；不将计划视为已经发布的实际数据。仅展示过去30天至未来30天窗口内的已公开计划，计划可能调整。

仍缺：国务院动态列表未接入，不能把人民银行覆盖说成全部政策覆盖。社交情绪和实时题材榜单没有接入。

成功快照保存在data/news，运行状态单独记录。去重依据原文链接，标题/摘要/源日期修订计为更新；全部失败保留旧有效数据。损坏最新文件尝试回退历史有效快照。当前保留最近30天资讯内容；发布时间未知仅按捕捉窗口管理，不能断言是最近发布。

成交额对比使用最近已保存的更早日期，两日共同代码、共同有效数值。明确显示“较日期快照”，缺交易日历时不冒称上一交易日。当前总额仍为导入范围汇总，不是交易所官方全市场总额。成交量只有两天股/手单位均已确认且相同才比较。

最新整体温度研究参考已从首页移入温度详情，与所选历史复盘日分别计算，缺指标仍不生成冷暖结论。
