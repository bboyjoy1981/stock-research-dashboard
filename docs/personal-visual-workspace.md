# 个人端图形化第一批

用户确认：个人端强调简单、一眼看懂；市场总览保留复杂数据。原仓位规则和人工评分不变，不自动修改策略、持仓或下单。

- 阶段目标仓位：移除三行重复资产表，使用进攻/防守/现金横向比例图；现有金额指标保留。图表明确是区间中值参考，不是实际持仓。
- 六项规则：四张阶段卡替代规则表，当前人工勾选对应阶段有红色标记。阶段由现有六项人工规则计算，不由市场温度转换。
- 六个持仓槽位：两排三列摘要卡，显示股票、市值、实际占比与目标区间；止损未设置时显示提醒。编辑区默认折叠，保留原输入key、字段、保存快照逻辑。
- 实际总仓：红点显示录入仓位，蓝色带显示原阶段参考区间；总资产为0时不生成比例，超过100%不截断隐藏。
- 市场背景：引用总览stocks快照、日期和涨跌结构，仅供核对，不写入六项评分；缺数据提示待补。
- 本批针对用户截图中的三处；个人首页其它历史/记录页面还未整体精简。未修改持仓数据库记录；历史表和下载保持原有功能。

测试：相关计算与页面63项通过；新增图形化、阶段和输入更新用例先失败后通过。全量回归474项通过（385.93秒），2条第三方弃用警告；本地8505健康检查返回200。浏览器运行时此前无法启动，本批不声明完成实屏视觉验收。
