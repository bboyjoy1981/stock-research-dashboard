# 板块细分

入口在侧边栏「核心市场工作台」，不藏在更多市场研究中。

全市场行业保留所选导入快照的原始行业口径，不宣称已经转换为申万或其他标准行业库。缺失行业进入未分类；细分行业有数据才展示。2026-10-09 快照核对：5227 只、91 个行业标签（含未分类）、4 只未分类，沪深范围缺北交所。

科技研究主题独立于行业，支持重复归属，包括 CPO / 光通信、PCB、半导体、存储、算力基础设施、软件 / AI、消费电子、机器人、低空经济、商业航天、国产替代。各主题按明确关键词匹配导入行业、细分行业、标签和概念；PCB 另保留用户参考图名单。分类不是业务核验，更不是官方概念成分库。CPO 仅匹配明确 CPO 标签，光通信不自动进入 CPO 环节。未匹配节点显示待补充可核验名单，不生成公司归属。

分类按钮带样本数量；个股为卡片，每页 12 只，所有匹配成员均能分页浏览，没有涨幅筛选。行情缺失显示横线。点击个股清除旧研究路径并跳转详情。页面不请求外部行情、不写持仓或个人记录；复用快照交易日。

此前选股工作台与 PCB 全景未删除。新页面仅接入内部 app.py，不扩大独立朋友试用站的授权页面范围。

新增测试先运行得到 5 个预期失败，再实现；验证包含行业缺失、下跌股票保留、主题重叠、CPO 不误归、PCB 名单、一级入口、卡片跳转与空主题。

只读复核后补充了上市板块不能充当行业、缺失细分与切板块清空搜索的回归测试（先失败后通过）。泛主题标签明确标为「泛标签匹配」，不误称未细分。PCB 新目录只展示参考名单与行情快照的交集；完整参考名单含未覆盖成员仍可在原 PCB 全景浏览。初轮全项目 513 项通过、2 条既有依赖弃用警告；最终变更另作全量复验。

## 首批产品依据名单（2026-10-10 核对）

`src/technology_references.py` 记录 8 家公司的 10 条环节归属及原始来源链接：中际旭创、新易盛、光迅科技、源杰科技、兆易创新、佰维存储、江波龙、澜起科技（光迅和兆易分别对应两个环节）。光通信主题 4 家、存储主题 4 家。仅匹配所选快照已有代码，不添加虚拟报价，不改原始行业。源杰引用2023年报，其余为官网产品资料。官网核对日期与行情交易日独立，当前产品研究分类不能用作历史成分回测。
